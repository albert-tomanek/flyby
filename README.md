## FlyBy
This is an app for any situation where you take multiple successive pictures of the same item. It lets you:

* Store all associated photos in a single file
* Align individual photos with each other
* Reorder photos in the sequence
* Animate the photo sequence and export it
* View photo pairs using 3D glasses
